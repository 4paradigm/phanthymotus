1归属纠正

卡片宿主

Perception Bundle 注册并暴露 controlled_spatial，不是 G1 Device Bundle。

算法面

FAST-LIVO2、地图/重定位、全局规划、EGO 和任务状态属于 perception。

硬件面

Driver 发布传感器与机身状态，并承载最终 SmartMotion / 高层运动安全门。

执行权

Perception 只产生 shadow proposal；永远不直接导入 Unitree SDK 或取得运动权限。

旧实现的定位：phanthymotus-driver/unitree/g1/controlled_spatial.py 是历史兼容参考，不再是新卡片正本。目标部署不得让 Driver 与 Perception 同时暴露同名工具。

2卡片契约与 Perception 路由

对外工具名保持不变

class ControlledSpatialPlugin:
    PREFIX = "controlled"

    def get_tools(self):
        return [{
            "name": "spatial",
            "type": "processor",
            "multiInstance": False,
            ...
        }]

当前 Bundle 组合后对外工具名正好是 controlled_spatial。直接把带下划线的全名设为 PREFIX 会被错误拆分。

业务 schema 严格保持 14 项

start_mapping、stop_mapping、tag CRUD、map CRUD/load、两种 navigate、wait、pause/resume/stop。

Perception 的 info 等框架生命周期作为内部 adapter 路径处理，不加入用户冻结的业务 action enum；实现前必须用契约测试锁死。

接口Perception 语义关键约束
topic_in由画布连接 Driver 的 MID360、IMU、RGB、Depth、机身/关节状态不绕过 Driver 直读硬件
topic_outstatus、map、global path、local trajectory、cmd_vel_shadow输出是算法结果/动作建议，不是物理执行
navigate_to_*创建 nav_id 后立即返回 navigating必须继续调用 wait_navigation_done
wait_navigation_done等待 arrived / blocked / stalled / canceled / errorstall_timeout 默认 90 秒且只计算非暂停无进展

6全局引导与 EGO 分工

地图尺度

A* / Theta* 在二维占据栅格产生跨房间路线，并按 G1 机体半径膨胀障碍。

局部目标

路线跟随器选择前方 2–4 米 subgoal，使目标始终位于 EGO 局部地图范围。

动态点云

EGO 用实时注册点云做局部优化；持续无解或偏航后触发全局路线重算。

障碍策略：mode=1 遇阻进入 BLOCKED 并零速；mode=0 才允许局部绕行与全局重算，N5 验收前必须返回 unsupported。

714-action 状态机

IDLE ──start_mapping──► MAPPING ──stop_mapping──► MAP_READY
  └────────load_map──► LOCALIZING ──quality ok──► READY
                                                   │
                                     navigate_to_* ▼
                           PAUSED ◄──► NAVIGATING ◄──► BLOCKED
                                         │
                      arrived / stop / error ──► READY
action 组核心语义
start/stop mapping.partial 工作目录；产物校验通过后原子发布地图
tag/list/delete/loadPOI 使用 map 帧；拒绝删除 in-use 地图；load 必须真实配准
navigate_to_tag / pose创建 nav_id 后非阻塞返回 navigating
wait_navigation_donecondition/event 收口到达、停滞、阻挡、取消或错误
pause/resume/stoppause 立即零速且不计 stall；stop 清空 route 与 EGO trajectory

8Shadow 与唯一安全执行权

Perception 输出

  • 只发布 map、path、trajectory、diagnostics 和 cmd_vel_shadow
  • 定位、cloud、command 过期时 proposal 清零
  • episode 录制 fail-open，但绝不影响动作门禁

Driver 执行

  • 部署时单独 armed，不由业务 action 开启
  • 首次现场档不高于 0.2 m/s
  • TTL、租约、主运控、急停、姿态与障碍门禁同时满足

9N1–N6 阶段门禁

N1 契约Perception tool、topic、TF、路由测试
N2 LIO频率、时钟、活性与资源
N3 定位地图 load、真实配准、连续 TF
N4 EGOroute、replan、fault injection、shadow
N5 执行0.2 m/s、TTL、停障、急停
N6 闭环多 POI、重定位、日志与视频

北京已有约 20 分钟 N2 阶段证据。按用户决定，后续不等待固定 30 分钟 soak 才推进；更长稳定性测试作为发布质量项。

10上海 G1 ready 后

固定只读检查：运行本 Perception 卡片目录下的无参数脚本；它委托 Driver 底层 preflight。
LIO 短采样：检查四路 topic、诊断、资源、外参和 namespace。
人工驾驶建图：现场 owner 显式启动/停止 mapping；Agent 不代执行机器人写操作。
产物验收：PCD header、点数、大小与 /tmp/nav_result.json 必须有真实证据。
重启重定位：有效地图后实现原点粗初值 + scan-to-map 精配准。
先 shadow 后低速：N3 后验证 EGO proposal；最后单约 0.2 m/s 有人值守窗口。
