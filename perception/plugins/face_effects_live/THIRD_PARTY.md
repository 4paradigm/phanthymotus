# Third party materials

- YuNet 2023mar ONNX: MIT, copyright Shiqi Yu. Official model URL, digest and notice are recorded in `models.json` and `licenses/YuNet.txt`. Model binaries are deliberately outside this source tree.
- OpenSeeFace models and adapted normalization / heatmap-offset decoding in `backends.py`, `osf_input.py` and `osf_decode.py`: BSD-2-Clause, copyright (c) 2019 Emiliana. Full notice in `licenses/OpenSeeFace.txt`. Source: https://github.com/emilianavt/OpenSeeFace/blob/master/tracker.py . No upstream tracking/identity implementation is imported. The adapted code returns x/y in canonical input pixel coordinates. ROUND5 retains the float32-before-resize preprocessing order when transporting compact original crops.
- ONNX Runtime: MIT; OpenCV: Apache-2.0 for current versions (included dependencies have their own notices); NumPy: BSD; ModernGL: MIT; psutil: BSD. Use the actual installed distributions' notices when shipping a container. This file is not a replacement for those distribution notices.
- `assets/`: original programmatically drawn demonstration art generated by `generate_assets.py`, with no external image or trademark assets.
- Acceptance-only portrait: Matplotlib v3.8.4 `sample_data/grace_hopper.jpg`, official source https://raw.githubusercontent.com/matplotlib/matplotlib/v3.8.4/lib/matplotlib/mpl-data/sample_data/grace_hopper.jpg . This US Navy portrait of Grace Hopper has a government/public-domain provenance record at https://library.arlingtonva.us/2019/08/19/rediscover-grace-murray-hopper/ . Input photo and derived videos remain in the local evidence directory, not the Card source or third-party services. Other countries' rights and deployment content choices require their own review. `messi5.jpg` was downloaded from OpenCV sample data during exploration and was NOT used for the reported benchmarks or included in the Card.
- Optional MediaPipe Tasks 0.10.21 and official Face Landmarker float16/1 bundle are exercised in round 2, with CPU/XNNPACK. Google's [Face Mesh V2 model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MediaPipe%20Face%20Mesh%20V2.pdf) explicitly states Apache License 2.0 (not inferred from a documentation footer). Artifact URL, digest and model-card URL are in `models.json`; Apache text is in `licenses/Apache-2.0.txt`. Transformation-matrix/blendshape outputs are disabled. Runtime never downloads a model, and model binaries are not redistributed here. Installed transitive libraries retain their own notices.
- Round 2 natural replay clips are excerpts of original White House / Obama Presidential Library US Government recordings documented by Wikimedia Commons, with PD-USGov source records. See `docs/face_effects_live/ROUND2.md` and its source manifest. Videos remain local evaluation evidence; commercial music/intros, logos and third-party inserts are not effect assets. This project does not claim endorsement by the depicted people.
- No InsightFace pretrained weights, commercial effect SDKs or BFM model data are included or used.

Model URLs follow upstream branches; the byte hashes are the immutable artifact identifiers. The fetch tool refuses an upstream change or an existing mismatching file. No claim is made that a GitHub commit pin was obtained when its API was unavailable.
