# PICO 遥操：通用输入、Driver 解算与执行卡片

状态：2026-09-22 用户批准实施；仅本地开发与离线验证，尚未部署或真机验收。

## 目标与边界

完整交付 Canvas 配置 → PICO 安装配对 → 双臂遥操与显示 → 结束收臂。
普通 ActuCore 内保留一张 `teleop`；天轶 Driver 内新增 `motion_control`，为已有 `arm` 增加连续目标输入。
仅迁移天轶双臂，保留 G1、既有 VLA 和 motus.control/1；本轮不实现手腿控制，不增加独立服务。
机器人承担接待期间不连接调试、不部署、不发送动作。Core 仅改所需配置、绑定和下载入口，保护用户其他修改。

## 三层与反馈

- `teleop`：OpenXR/WSS/RTC、配对、输入有效性、双握把、相对映射、通用末端目标。
- `motion_control`：控制用 URDF/TCP/标定、FK/IK、碰撞、执行器映射、会话与收臂。
- `arm`：最新关节目标流、共享执行门、最终限位限速、厂商发布、实测反馈与停止。
- `arm → motion_control` 使用 Driver 内部实测快照和执行记录，不新增中转 topic 或 Canvas 边。
- `motion_control → teleop` 复用现有反馈 topic；Canvas 随正向连线自动建立并显示反馈边，不纳入启动依赖图。
- `teleop → PICO` 复用现有 WSS visualization；异步显示不阻塞控制。

## 协议与运行契约

- 新增 motus.control/2，保留 /1：沿用 mode/values/groups，补 boot/session/seq/source_seq/mapping_epoch、单调时钟期限和鉴权。
- 上游 eef_pose 是描述坐标系下 xyz 米与 xyzw 单位四元数；下游 joint_position 是描述关节顺序的 rad。
- 同机 domain 42、版本化 JSON、最新目标；低频管理继续 MCP；秘密不发布到 topic。
- Driver info 声明端口、末端、坐标系、模型/标定版本、单位、资源；不能仅凭维数推断语义。
- 双臂使用一个原子命令，包含左右各 7 关节的 arm_l/arm_r group，共用同一执行租约；后续手开合是独立 normalized 组，不混入 7 维位姿。
- 每次重新使能用同一份新鲜 FK 快照建立映射，丢弃旧映射代次及过期求解。求解不能延长原输入寿命。
- 执行循环 50 Hz，默认 1 rad/s；沿用已验证时效，不新增首次接管低速、累计行程或误差百分比门槛。
- 只有一个共享执行门：原动作和流输入均检查资源，避免重复速度/恢复状态机。
- 碰撞/不可达保持最后有效位置附近，不增加越界搜索；继续处理最新输入，有效后同会话恢复。
- 松握保持，重握重新建基准；结束停止接收输入，按实测反馈收臂至厂商模型双臂零位（本轮自然下垂目标，14 关节 q=0），确认后释放；立即停止不收臂。
- 真故障与短暂求解失败分开，停止未确认不能报告成功。禁止旧目标重放或重启后自动运动。
- Shadow 共用算法但隔离会话与缓存，无执行租约和硬件命令；Live 建立新会话与基准。
- Driver 生成实际/IK/最后有效参考线与失败原因，保持原平视方向、躯干和 held 显示，不用旧线伪装新解。

## 安装、配对与 Canvas

- Canvas 提供二维码、短地址、APK 版本。PICO 浏览器下载并经系统安装后，回页面点击“打开并连接这台机器人”。
- 深链接预填机器人身份、endpoint、证书与邀请；从安装器直接打开而没有邀请时进入发现页，不猜测机器人。
- 邀请由认证 Canvas 签发，15 分钟、单次使用、可撤销、绑定机器人；下载不消耗旧 120 秒配对窗口。
- 已配对冷启动自动连接，提供取消/切换/撤销；身份变化停止重试；连接不授予运动权限。
- 固定签名 release APK 作为带版本/签名/SHA256 的制品进入普通 ActuCore 镜像，Core 受控代理下载。构建源为确定性 gzip，分别核对压缩制品与原 APK 的大小/哈希，用户下载原 APK。
- 不提交 APK 或私钥；不改 bot 服务、不新增遥操构建开关；签名不兼容时明确迁移，不静默卸载。
- 模板为 teleop → motion_control → arm，自动显示运动反馈边。按输出端口分别协商能力，保留旧单端口。
- 日常配对、模式、输入映射、模型/标定、速度、启停从卡片配置完成；Canvas/PICO 共用开始/结束收臂/立即停止状态。
- 下游准备完成后才允许使能；项目停止先收臂和释放再停止下游，失败保留状态。
- 缺模型不隐藏安装配对，单卡配置故障不能拖垮普通 ActuCore。
