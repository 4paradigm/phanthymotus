# 移除本地回声拦截，统一由 Jev 判断

## 范围与契约

- 删除文本规范化匹配及本地 robot_echo/reject 分支，不新增替代规则。
- 保留近期 TTS 参考的采集、过期、失败清理，仅供 Jev 上下文使用；参考不代表实际播放确认。
- 逐字重复、错字、片段均交 Jev。有效 ignore 拒绝语音；uncertain、请求超时和排队预算耗尽回退实时默认模式。
- Jev 关闭走旧链路。权限、去重、结构校验、其他错误策略、生命周期与至多一次交付不变。
- 同步测试与操作文档；提交推送现有 PR #254，精简描述，申请 Bot review 并处理有效意见。
- 不部署、不合并、不运行付费 API 或真机实验；旧版含本地过滤的实验不作为新版效果证据。

## 实施与验证

1. 删除本地匹配辅助函数、硬拒绝分支及失效注释。
2. 覆盖精确重复/片段/错字调用模型、模型允许和忽略、匹配文本超时/排队过期、开关关闭、参考过期和失败清理。
3. 运行路由定向、Core 全量及 diff 检查；既有三模式、生命周期与一次交付回归必须通过。
4. 检查 README、接口和操作说明；入口和 API 契约不变，不改无关说明。历史计划明确被本计划取代的条款，保留真实历史结果。
5. PR 按问题、方案、验证、代价四节重写，最新提交等待独立 Bot 结论，不沿用旧 head 通过记录。

## 后续实验设计（仅设计，未执行）

只比较 Jev OFF / ON 两组；相同代码、身份、默认模式、ASR/TTS、麦克风、音量和生产 2 秒预算，不增加本地过滤组。

- 固定回放：20 条开发样本与 100 条封存测试样本按原始会话隔离，避免近重复泄漏。测试集五类各 20 条：正常提问、连续对话/称呼错字、逐字回声、错字/片段回声、明确非面向机器人。独立人工标注应否接入及忙碌时路由；模型输出不能作真值。固定随机种子、两组交替、每条各三次，超时纳入统计。
- 真机：四类各三套脚本（正常交互、纯机器人回声、旁人聊天、双讲），每组重复两次，共 48 次；AB/BA 平衡顺序，重置相同起始上下文并记录实际 TTS 播放。
- 主指标：每 100 条无效候选引起的实际主 LLM 请求数（含重试）。回放只能报告接入代理指标，不能冒充真实调用节省。
- 守护指标：有效信息召回、误拒绝、错误中断；分别报分子/分母、分场景结果及重复波动，不能只报过滤率。召回下降需逐例复核，不能为突出优势隐藏失败。
- 延迟：ASR 完成→路由完成、→TTS 请求及→实际出声分别统计 p50/p95，报告排队、API、超时及端到端未完成数。预算内成功样本与全样本分开。
- 消耗：主 LLM/Jev 请求与 usage 分开，缓存/非缓存输入和输出分开；取消请求缺 usage 记未知，不能据此承诺净成本下降。
- 国内 API 仅为条件性预期：同模型且跨境网络占比显著时可能大幅改善；未测网络/排队/推理分解前不给加速比例。
