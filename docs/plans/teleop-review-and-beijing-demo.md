# 遥操整理、评审与北京 G1 卡片展示

## 范围与边界

用户已确认天轶当前遥操效果良好。天轶正在承担展厅接待，本任务不访问、部署或调试天轶。离线整理主仓及天轶 Driver 的当前实现，分别提交并申请 bot review；不自动合并。北京 G1 仅展示 Canvas 卡片与 Shadow，不继承天轶硬件验收，不启动机器人动作。

## 交付步骤

1. 核对源码、来源许可证和现有部署证据，保留原工作树及内部现场资料。
2. 完成 Canvas 使用手册和架构问题说明。优先说明实际配置、配对、标定、开始、暂停、恢复、结束与停止流程，不将尚未支持的机型动作显示为可用。
3. 复跑必要的 Python、真实回环 WSS/RTC、原生 host 与浏览器检查；在正确 G1 数值环境验证模型与求解。测试替身不代表真机执行。
4. 将公开源码、通用工具、模型、许可证、测试与文档提交到最新主线审查分支，分别创建或更新 Draft PR 并触发 bot review。现场固定 SHA 的发布／恢复脚本、原始录制、私有日志、凭据和长篇站点流水不进入本次公共 PR。
5. 北京 G1 保留现有 VLA 源码和普通 Driver，构建单一普通 ActuCore，遥操通过 driver_joints 只读反馈展示。Core 仅叠加本卡片所需代理、元数据与前端补丁，保留现场其他改动。部署前确认无编辑占用、项目停止及无任务；核对服务变更和回滚。
6. 验证页面真实显示、配置保存／读回、G1 不支持操作的隐藏、关节反馈及零执行权。提供可访问地址与点选步骤。配对和实体输入另记；没有进行物理动作验收。
