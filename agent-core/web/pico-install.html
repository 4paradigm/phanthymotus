安装遥操
  1. 点击上方按钮下载；下载完成后，打开安装包并按系统提示确认安装。
  2. 安装完成，直接点击打开。
  3. 电脑端打开遥操卡片的允许新设备配对，在 App 中选择发现的机器人。核对两端配对码、确认后，连接资料会自动保存。

头显和机器人需要连接同一局域网。下次打开 App 会连接已配对机器人；开始遥操需要另行确认。

已有 App，使用连接邀请

也可以在电脑端生成一次性连接邀请，在头显浏览器打开邀请链接。

安装或连接遇到问题
  • 安装入口在哪里：在浏览器下载列表中打开刚下载的安装包。
  • 提示安装来源权限：按系统提示允许当前浏览器安装，然后继续。
  • 没有发现机器人：检查同一 Wi-Fi、访客网络隔离，点击 App 的“重新查找”；仍找不到可展开“连接帮助”。
  • 配对窗口过期：在电脑端重新点击“允许新设备配对”，再选择机器人。
  • 旧测试版提示签名冲突：联系维护者安排迁移，避免直接卸载丢失配对。
